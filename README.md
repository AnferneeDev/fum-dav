# Fumigaciones David

Landing page responsive para **Fumigaciones David**, basada en el concepto visual azul, rojo y blanco de la marca.

## Stack

- React
- Vite
- Lucide React
- CSS responsive sin framework

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Estructura

La home está dividida en componentes: `Header`, `Hero`, `Services`, `Benefits`, `About`, `ContactBanner` y `Footer`.

> Los datos de contacto incluidos son placeholders y deben sustituirse por los datos reales del negocio.
